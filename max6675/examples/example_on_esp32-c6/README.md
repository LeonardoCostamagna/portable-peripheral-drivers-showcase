# ESP32-C6 Example Application

---

The `examples/example_on_esp32-c6/` directory demonstrates how to integrate the driver into an ESP-IDF project.

This application serves as a demonstration project showcasing how to integrate and utilize the MAX6675 thermocouple driver on an **ESP32-C6**. Key functionalities include:

* **SPI Bus and GPIO Configuration:** Initializes the ESP32-C6 master SPI bus and configures the Chip Select (CS) pin as a GPIO output for manual software control.
* **Driver Integration:** Demonstrates the driver’s dependency injection pattern by providing platform-specific SPI read and CS control callback functions.
* **Sensor Status Monitoring:** Continuously retrieves temperature readings while checking for error conditions such as disconnected or open thermocouple circuits.
* **Periodic Logging:** Enters a continuous loop to log the measured thermocouple temperature or warning messages at regular intervals using FreeRTOS tasks.

## Prerequisites

To build and run the example, you need:

* **ESP-IDF environment:** Host development environment provided by Espressif.
* **ESP32-C6-DevKitC-1:** Development board.

## Hardware Connections

| Signal / Pin | ESP32-C6 Pin | Description |
| :--- | :--- | :--- |
| **MAX6675 SO** | GPIO 2 | SPI Master In Slave Out (MISO) |
| **MAX6675 SCK** | GPIO 6 | SPI Serial Clock |
| **MAX6675 CS** | GPIO 4 | Chip Select (Software Controlled) |

## How to Build and Flash

1. Open a terminal and navigate to the example directory:
```bash
cd examples/example_on_esp32-c6
```

2. Set up your ESP-IDF environment variables (if not already loaded):

```bash
. $HOME/esp/esp-idf/export.sh
```

> **Note:** This path is generic. Make sure to adjust it to match the actual location of the export.sh script on your host machine.

* This command loads the toolchains, paths, and environment variables required to use the ESP-IDF framework in your current terminal session.

3. Build the project:

```bash
idf.py set-target esp32c6
idf.py build
```

* `idf.py set-target esp32c6`: Configures the project for the target microcontroller architecture (in this case, the ESP32-C6).
* `idf.py build`: Compiles the source code, links libraries, and generates the binary firmware image.

4. Flash the firmware and monitor the serial output:

```bash
idf.py -p /dev/ttyUSB0 flash monitor
```

> **Note:** Replace `/dev/ttyUSB0` with your actual port if necessary.

* `flash`: Uploads the compiled binary firmware to the connected development board over the specified serial port.
* `monitor`: Opens the serial console to view real-time logs output generated by the device.
